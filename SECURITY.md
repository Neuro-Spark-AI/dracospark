# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/Neuro-Spark-AI/dracospark/security/advisories/new)
for this repository. Do not open a public issue for a suspected vulnerability.

Include what you found, how to reproduce it, and the affected files or versions. We
will acknowledge the report, investigate, and coordinate a fix and disclosure with you.

## Scope notes

Dracospark executes kernel code generated by an LLM agent on the TPU hosts you
configure, and the SSH evaluator runs commands on those hosts with the credentials
you provide. Run it only against machines and accounts dedicated to this work, keep
SSH keys and cloud credentials out of configs you share, and review generated
kernels before using them elsewhere.
